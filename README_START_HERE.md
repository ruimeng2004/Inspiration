# 从这里开始

1. 把整个 `ICML_claude` 文件夹放到桌面。
2. 在终端运行：`cd ~/Desktop/ICML_claude && claude`
3. 第一条任务可以直接发送：

```text
请先阅读 CLAUDE.md、PROJECT_STATUS.md、docs/LITERATURE_SUMMARY.md 和 docs/IMPLEMENTATION_PROTOCOL.md。
然后只做以下工作：通过 xzhanglab 部署 code/evidence_rl_project，运行 CPU 测试和只读 GPU 检查。
不要启动 GPU 任务，不要结束进程，不要下载数据，不要修改历史实验目录。
完成后汇报结果，并更新 PROJECT_STATUS.md。
```

部署脚本：`code/evidence_rl_project/deploy.sh`。研究网页：`web/icml2027-research-hub.html`。
