# Evidence RL
CPU core for the ICML 2027 visual-evidence project.

Run `bash deploy.sh` on your own computer. It does not download data, start GPU work, stop processes, or change historical runs.

Tested: parser, budget environment, TRACE baseline, evidence group, credit, Gittins, allocators.
Not finished: `backends/hf_qwen.py`, dataset adapters, GRPO, LoRA training.
